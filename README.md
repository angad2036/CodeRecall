# CodeRecall 🧠

### Don't Just Solve DSA. Understand Every Step.

CodeRecall is an interactive Data Structures and Algorithms learning platform designed to help students move beyond memorizing solutions and truly understand how algorithms work.

Learn, solve, visualize, and explore multiple approaches to programming problems through an interactive learning experience.

---

## 🚀 Features

- **Structured Problem Library:** Explore DSA problems organized by topics and difficulty levels.
- **Interactive Code Execution:** Understand algorithm execution through step-by-step code highlighting.
- **Algorithm Visualization:** Visualize arrays, pointers, HashMaps, searching and other algorithm operations.
- **AI-Assisted Explanations:** Learn problem intuition and understand solutions through explanations.
- **Animated Learning:** Explore visual teaching experiences for understanding algorithms.
- **Multiple Solutions:** Compare different approaches to solving programming problems.
- **Multi-Language Learning:** Explore solutions in Java, C++ and Python.
- **Learning Dashboard:** Navigate your DSA learning journey.

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Firebase
- Gemini API

## ⚙️ Run Locally

### Prerequisites
- Node.js
- npm

### 1. Clone the repository

```bash
git clone https://github.com/angad2036/CodeRecall.git
```

### 2. Navigate to the project

```bash
cd CodeRecall
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env.local` file using `.env.example` as a reference.

Add the required Gemini API key and other environment variables.

Never commit your API keys.

### 5. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 🎯 Vision

The goal of CodeRecall is to make DSA learning more visual, interactive and intuitive.

Instead of simply showing students what the solution is, CodeRecall aims to teach them why the solution works and what happens at every step.
